# 知识库去重

> 起因：150 题评估实测发现，同一句话在答案里**重复出现两遍**（一版完整、一版是被折行切碎的）。
> 根因不是代码，而是**知识库里存了同一份文件的两个版本**。

## 为什么会重复

公文类知识库的典型现象：**「印发通知」里含「附件全文」**。
实测那组是：

| 版本 | 片段 | source_title |
|---|---|---|
| 细则本体 | 149-153 | 燕山大学本科生学业预警工作实施细则 |
| 印发通知（含全文） | 222-226 | 关于印发《燕山大学本科生学业预警工作实施细则》的通知 |

两份正文一字不差，检索会把它们**同时召回** → 答案里同一句出现两遍。

## 判定为什么必须用「文档级」而不是「片段级」

第一版工具用片段级包含度（4-gram，阈值 0.60），结果 **7 组里有 6 组是假阳性**：

| 误判 | 实际情况 |
|---|---|
| 「录取分数」vs「录取查询」 | 两个不同的官方链接，共享的是 URL 前缀 |
| 「学科实力/ESI」vs「学位授权点」 | 一个讲重点学科，一个讲学位点 |
| 「师资/院士」vs「一流专业/工程认证」 | 完全不同的主题 |

同领域文档天然共享大量术语，**短片段共享样板文本**更会让包含度虚高。

改成**文档级**判定后就只剩那一组真重复：

> 只有当 A 文档的**大多数**片段（默认 ≥60%）都能在 B 文档里找到近重复（包含度 ≥0.70）时，
> 才判定 A、B 同源。

无 `source_title` 的片段各自成组、不参与"文档"比对 —— 它们多是手工短条目，本来就容易被样板文本误导。

## 安全闸（三道）

1. **评估集保护**：`golden_set.csv` 里所有 `gold_chunk_ids` **绝不删除**。
   这道闸是必需的 —— 第一版工具曾建议删 `id=207`（9-05 特意新建的「学科建设」锚点片段，
   评估集 N04 的 gold）和 `id=111`（M23 的 gold），删了会让 Recall 莫名其妙崩掉。
2. **只提议不自动删**：默认只输出清单（`--review-csv`），加 `--apply` 才执行。
3. **先备份**：`--backup` 把待删片段的完整内容落盘，万一判错还能重新导入。

删除走 `DELETE /api/knowledge/chunk/{id}`（连带删 PGVector 向量）。
**直连 MySQL 删行会留幽灵向量** —— 检索仍能命中一个库里不存在的 chunk_id，界面上看不出来。

## 用法

```powershell
$PY = "D:\Program\Python\Anaconda3\envs\myenv\python.exe"

# 1. 只分析 + 落清单
& $PY tools\kb-dedupe\find_duplicates.py --review-csv tools\kb-dedupe\duplicates.csv

# 2. 人工复核 duplicates.csv 与终端输出（看内容，别只看数字）

# 3. 执行（先备份）
& $PY tools\kb-dedupe\find_duplicates.py --apply `
    --backup tools\kb-dedupe\deleted_backup.txt `
    --review-csv tools\kb-dedupe\duplicates.csv
```

参数：`--containment`（片段级，默认 0.70）、`--doc-coverage`（文档级，默认 0.60）、
`--no-gold-protect`（关掉评估集保护，不推荐）。

## 删完必做的两件事

**① 重映射评估集的 gold id。** 工具会在删除前提示哪些待删片段被 gold 引用；
删完要把 `tools/eval/golden_set.csv` 里这些 id 改成保留版的对应 id。实测影响 7 道题：

| 题号 | 原 gold | 改后 |
|---|---|---|
| N22 | 149,222 | 149 |
| N38 | 223 | 150 |
| N39 | 224 | 151 |
| N40 | 226 | 153 |
| N61 | 225 | 152 |
| N62 | 226 | 153 |
| M14 | 137,149,225 | 137,149,152 |

映射关系（待删 → 保留）由片段级包含度给出：`222→149 223→150 224→151 225→152 226→153`，
其中 `224→151` 与 `225→152` 的包含度是 **1.000**（完全同内容）。

**② 重跑验收**：

```powershell
pwsh tools\verify_all.ps1
```

确认兜底率 / 逐字保真 / 超纲拒答率这些红线没有退化。若知识片段数变了，
顺手看一眼 Grafana 的 `rag_corpus_size` 是否同步（BM25 语料有 30s 懒刷新）。
