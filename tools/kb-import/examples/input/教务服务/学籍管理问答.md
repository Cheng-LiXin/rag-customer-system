# 学籍管理问答

## 如何申请贫困生补助

申请贫困生补助需准备以下材料：

- 《家庭经济困难认定申请表》
- 本人身份证复印件
- 家庭经济情况说明（父母收入证明等）

办理流程：将材料交至所在学院学工办，学院初审后统一上报学生资助管理中心，审核通过后于 15 个工作日内发放补助。

咨询电话：010-12345678。

## 学生证丢失怎么补办

学生证丢失后应第一时间在校园网挂失，避免被他人冒用。

补办流程：下载《学生证补办申请表》→ 学院盖章 → 携带一张一寸照片到学生事务大厅办理，工本费 20 元，办理时间约 3 个工作日。

## 转专业需要什么条件

转专业一般在大一或大二学年末开放申请。

基本条件：无违纪处分记录；必修课无挂科；接收专业有名额。

需要提交转专业申请表并参加接收学院的考核面试。
