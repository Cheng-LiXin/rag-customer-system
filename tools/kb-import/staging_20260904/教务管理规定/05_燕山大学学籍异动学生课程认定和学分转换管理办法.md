# 燕山大学学籍异动学生课程认定和学分转换管理办法

为推进和完善学分制教学管理制度，满足学生多样化的学习要求，保证人才培养质量，规范各类学籍异动后学生课程认定和学分转换相关工作，结合我校实际，特制定本办法。

第一条本办法适用于转专业（不含入学新生）、转学、留降级、复学、提前毕业等校内学籍异动情况。

第二条学生学籍异动进入新的年级或专业学习，必须修满该年级该专业培养计划规定的全部课程。对于学生学籍异动前已经修读的课程，需要审核其是否符合异动后的培养计划的要求。

第三条学生学籍异动前已经修读通过的课程， 若与异动后该年级该专业所需修读课程教学内容相同或相近，同时符合下列条件，可以认定该课程符合新的培养计划要求，承认其已经取得的成绩（学分）：

（一）异动前课程符合异动后该年级该专业人才培养的要求，可支撑毕业要求的达成。若一门课程申请认定和转换为多门课程，应确保该门课程与申请转换的各门课程教学内容的完整性、连续性。

（二）异动前已修读单门课程的学时（学分）数不低于异动后需要修读课程学时（学分）数，或异动前已修读单门课程的学时（学分）数低于异动后需要修读课程学时（学分） 数，差额不超过理论8学时/实验16学时（0.5学分）。

第四条学生学籍异动前已经修读通过的课程，不符合第三条的要求，可作为辅修课程在学生成绩单上保留。异动后培养计划已开设的课程及无法实施课程认定和学分替换的课程需要补修，补修课程成绩记为正考成绩。

第五条课程成绩评定原则

（一）学籍异动前一门课程认定为异动后一门课程的，课程成绩按异动前成绩直接认定。

（二）学籍异动前多门课程认定为异动后一门课程的，课程成绩按异动前各门课程平均分进行认定。

（三）学籍异动前一门课程认定为异动后多门课程的，每门课程成绩均按异动前课程成绩认定。

第六条课程认定和学分转换程序

（一）学生在学籍异动后， 根据学院和专业指导，认真了解异动后专业（年级）培养计划， 在教务管理系统中，提出课程认定和学分转换申请。

（二）学生提出申请后专业负责人、教学管理人员根据本办法规定的原则依次进行网络审核、认定，确定学籍异动前所学课程是否可认定为学籍异动后该年级该专业课程、认定后的成绩等级；学院教学副院长审核批准后执行。学院从教务管理系统导出审批材料（加盖学院公章）报教务处备案。

（三）为了保证课程认定和学分转换工作的严肃性，教务处对课程认定与学分转换结果保留进一步审核的权利，教务处将组织专家抽查和复审，如发现问题，将退回要求学院重新组织认定审核。

（四）学籍异动学生课程认定及学分转换的集中受理时间为每学期开学的第1-4周。

第七条各学院在进行课程认定和学分转换审批时，应及时将不符合上述规定、不能实施课程认定和学分转换的课程告知学生，以免影响学生相关课程的修读。

第八条本办法自发布之日起施行，解释权归教务处。
